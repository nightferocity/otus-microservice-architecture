# Пользовательские сценарии

## UC-1. Заказ с самовывозом

Пользователь: Клиент

Основной сценарий:
1. Клиент выбирает магазин.
2. Просматривает меню.
3. Добавляет товары.
4. Выбирает самовывоз.
5. Выбирает способ оплаты.
6. Подтверждает заказ.
7. Получает время готовности.
8. Получает маршрут до магазина.
9. Забирает заказ.

## UC-2. Заказ с доставкой

Пользователь: Клиент

Основной сценарий:
1. Клиент выбирает магазин.
2. Просматривает меню.
3. Добавляет товары в заказ.
4. Выбирает доставку.
5. Система проверяет, доступна ли доставка у выбранного магазина.
6. Клиент указывает адрес доставки.
7. Клиент выбирает способ оплаты.
8. Подтверждает заказ.
9. Магазин принимает заказ.
10. Система назначает курьера.
11. Курьер получает адрес и маршрут.
12. Курьер доставляет заказ клиенту.

## UC-3. Просмотр акций

Пользователь: Клиент

Основной сценарий:
1. Клиент открывает приложение или сайт.
2. Система показывает национальные акции.
3. После выбора магазина система показывает локальные акции магазина.
4. Клиент добавляет товар по акции в заказ.

## UC-4. Управление локальными акциями

Пользователь: владелец франшизы или уполномоченный сотрудник магазина.

1. Пользователь входит в административный интерфейс.
2. Выбирает свой магазин.
3. Создает новую локальную акцию.
4. Указывает:
   - название;
   - описание;
   - период действия;
   - условия предоставления скидки.
5. Сохраняет акцию.
6. Покупатели выбранного магазина видят предложение в течение указанного периода.

## UC-5. Управление общенациональными акциями

Пользователь: сотрудник головной компании.

1. Пользователь входит в административный интерфейс.
2. Создает новое специальное предложение.
3. Указывает условия и срок действия акции.
4. Выбирает территорию ее действия.
5. Публикует акцию.
6. Покупатели соответствующих магазинов видят новое предложение.

## UC-6. Получение заказа водителем

Пользователь: водитель.

1. Водитель получает информацию о новом заказе на доставку.
2. Видит магазин, в котором необходимо забрать заказ.
3. Получает маршрут до магазина.
4. Забирает заказ.
5. Получает адрес клиента и маршрут до него.
6. Доставляет заказ покупателю.
7. Подтверждает завершение доставки.

## UC-7. Обработка заказа сотрудником кухни

Пользователь: сотрудник кухни / сотрудник магазина.

1. Сотрудник видит поступивший заказ.
2. Просматривает состав заказа и пожелания клиента.
3. Приступает к приготовлению заказа.
4. После приготовления отмечает заказ как готовый.
5. Для самовывоза заказ ожидает покупателя./Для доставки готовый заказ передается водителю.
